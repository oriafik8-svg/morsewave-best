# 🎉 קהוט חוגגים 80 לסבא צדוק!

משחק שאלון בסגנון Kahoot, מותאם אישית ליום ההולדת ה-80 של סבא צדוק.
בנוי ב-HTML/CSS/JavaScript עם סנכרון בזמן אמת דרך **Firebase Realtime Database**.

## 📁 הקבצים
- `index.html` – מבנה הדף (דף אחד: בית / מנחה / שחקן)
- `style.css` – עיצוב חגיגי, קונפטי, כותרת 80, כפתורי צבעים
- `app.js` – כל לוגיקת המשחק והחיבור ל-Firebase

---

## 🔧 שלב 1 – הקמת Firebase (חינם, 5 דקות)

1. היכנסו ל-<https://console.firebase.google.com> וצרו פרויקט חדש.
2. בתפריט הצד בחרו **Build → Realtime Database → Create Database**.
   - בחרו מיקום, ואז **Start in test mode** (מאפשר קריאה/כתיבה לחגיגה).
3. בעמוד הראשי לחצו על אייקון **</>** (Web) כדי לרשום אפליקציית Web, ותקבלו אובייקט `firebaseConfig`.
4. פתחו את `app.js` והדביקו את הערכים במקום המסומן:

```js
const firebaseConfig = {
  apiKey:      "...",
  authDomain:  "...",
  databaseURL: "https://XXX-default-rtdb.firebaseio.com",  // ⚠️ חובה!
  projectId:   "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId:       "..."
};
```

> **חשוב:** ודאו שקיים שדה `databaseURL`. בלעדיו הסנכרון לא יעבוד.

### הפעלת Authentication (חדש – חובה!)
המערכת דורשת התחברות (יוצר ושחקנים). ב-Firebase Console:

1. **Build → Authentication → Get started**.
2. תחת **Sign-in method** הפעילו שני ספקים: **Google** ו-**Email/Password**.
3. תחת **Settings → Authorized domains** הוסיפו את הדומיין של GitHub Pages
   (למשל `your-username.github.io`), אחרת התחברות Google עם חלון קופץ תיחסם.

### כללי אבטחה (Rules)
מכיוון שיש עכשיו התחברות ושמירת משחקים אישיים, מומלצים הכללים הבאים תחת
**Realtime Database → Rules** (משחקים חיים פתוחים לכל המשתתפים; המשחקים השמורים פרטיים למשתמש):

```json
{
  "rules": {
    "games": {
      "$pin": { ".read": true, ".write": true }
    },
    "shared": {
      ".read": true,
      "$sid": { ".write": "auth != null" }
    },
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid == $uid",
        ".write": "auth != null && auth.uid == $uid"
      }
    }
  }
}
```

## 🚀 שלב 2 – העלאה ל-GitHub Pages

1. צרו מאגר (repository) חדש ב-GitHub, למשל `saba-80`.
2. העלו את שלושת הקבצים: `index.html`, `style.css`, `app.js`.
3. בהגדרות המאגר: **Settings → Pages → Source → Deploy from a branch → main / (root) → Save**.
4. אחרי דקה תקבלו כתובת כמו: `https://<שם-משתמש>.github.io/saba-80/`

---

## 🎮 שלב 3 – זרימת השימוש

1. **התחברות** (חובה לכולם): במסך "פרופיל" מתחברים עם Google או אימייל.
2. **יצירת משחק**: לוחצים "ליצור" → "המשחקים שלי" → "➕ משחק חדש".
   בעורך כותבים שאלות, מוסיפים **שאלת 4 תשובות** או **אמת/שקר**, מסמנים את הנכונה (✓),
   ואפשר Ctrl+B להדגשה ו-TAB להשלמת דוגמה. המשחקים נשמרים אוטומטית ("קהוט עם סבא 1"...).
   אפשר לערוך, לשנות שם, לשכפל ולמחוק משחקים.
3. **הרצה**: מהעורך "▶️ התחל משחק" (או ▶️ מרשימת המשחקים) → מסך "יוצר חדר..." → לובי.
4. **לובי**: מוצגים PIN ו-QR חי, רשימת שחקנים עם תמונה, וסליידר **זמן הצבעה (10–60 שנ')**.
   כפתור "התחל משחק" נפתח כשיש **לפחות 2 שחקנים**.
5. **המשחק**: ספירה 5→1 לפני כל שאלה, טיימר, מונה הצבעות, גרף, תשובה נכונה,
   טבלת **TOP 5**, ובסוף **פודיום דרמטי** (3→2→1 עם פוקוס על המנצח) וקונפטי! 🏆

השחקנים בטלפון רואים רק את כפתורי הצבעים/צורות (4 או 2 לאמת/שקר).
